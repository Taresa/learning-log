# Session 4: GitHub front door

**Date:** 2026-11-22

## What I built

- A profile README in the special [Taresa/Taresa](https://github.com/Taresa/Taresa) repo, written for hiring managers and freelance clients.
- A profile bio and pinned repos.
- Pushed the date removals on my website, so the live site matches the README.

## The concept

- A repo named after your username becomes your profile landing page.
- Pins are a curated shelf. I choose what a visitor sees first.
- Green squares signal consistency, so small regular commits beat rare big ones.

## What I learned

- A commit is not a push. Committing saves the work locally, and pushing is what publishes it. I now check that the summary says both.
- Review drafts so they don't claim things that haven't shipped yet. Every "in progress" label has to be true on the day it goes live.
