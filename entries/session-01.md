# Session 01: First Claude Code tour

**Date:** 2026-11-20

## What I built

- The [hello-claude](https://github.com/Taresa/hello-claude) repository, initialized and published to GitHub.
- A README that frames the repo as a build portfolio: who I am, how I work, and three planned projects (Business Analysis Toolkit, Food Rescue Pickup Planner, AI Dispatch Agent).
- A progress log table in that README, to be updated each session.

## What I learned

- Claude Code works best when I treat it like a development partner and keep the product decisions (scope, priorities, what "done" means) on my side.
- Publishing early, even with only a README, makes the program real and gives later work a place to land.

## What I'd do differently

- Decide up front how progress will be recorded. A one-line table row in the README can't hold the reasoning behind decisions, which is what led to this separate log.
