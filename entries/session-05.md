# Session 05: Reading my own site

**Date:** 2026-11-22

## What I built

- Had Claude Code map my website's code and explain it a few lines at a time, so I can read the page I shipped.
- Added "Show details" toggles to my Experience cards, using native HTML with no JavaScript.
- Removed my personal email from the live site and reworded the footer to point to GitHub.
- Started a [glossary](../glossary.md) of the terms I've met.

## What I learned

- Review what was actually done, not what I asked for. The last website commit's message named two changes, but its diff held one. The other had shipped in the commit before.
- Removing my email from the live page doesn't remove it from earlier commits. The history still has it.
- Reading a page's structure, then its styles, makes a site I can't write feel like one I can edit.

## What I'd do differently

- Check the commit summary and diff before every push, not after.
- Ask for the glossary entries as I go, so each term is fresh when I log it.
