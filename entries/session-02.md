# Session 02: Setting up the learning log

**Date:** 2026-11-21

## What I built

- This `learning-log` repository: a README stating purpose and structure, and an `entries/` folder with one file per session.
- Backfilled the entry for session 01, so the log is complete from the start of the program.
- Connected the repo to GitHub at [Taresa/learning-log](https://github.com/Taresa/learning-log) and pushed to `main`.

## What I learned

- Separating the log from the portfolio keeps each one clean: hello-claude shows what shipped, and this repo shows how and why.
- A fixed three-part entry format (built, learned, would change) removes the blank-page problem and makes entries comparable across weeks.
- Asking Claude Code to explain each git command as it ran made the workflow (init, add, commit, remote, push) easier to follow than reading documentation.

## What I'd do differently

- Create the log structure in session 01, when the details were freshest, instead of reconstructing them a day later.
